# SRIC Core 0.5.13

Date: 2026-08-10

## Guided Web Security Console

This release replaces the CLI-like Web interaction model with an operation-oriented GUI shared by Sentinel Forge products.

### User-facing changes

- The Workbench is presented as a Security Console with Operations, Configure, and Recent Activity areas.
- The Advanced console navigation entry is removed from the primary UI.
- Free-form `Additional arguments` / `Advanced argv` input is removed.
- Flags render as checkboxes or explicit Default / Enabled / Disabled selectors.
- Closed option sets render as select or multi-select controls.
- Numeric parameters render with number inputs and available bounds.
- Repeated and fixed-arity values render as structured list/value controls.
- Sensitive values remain password-style fields and are still covered by backend redaction.
- Operation cards show human-readable capability names rather than requiring users to recognize command syntax.
- Mutating actions use explicit approval controls; destructive actions add a second impact acknowledgement instead of requiring users to type a CLI approval phrase.

### Architecture

The CLI remains the canonical capability implementation. The Web catalog converts the real Typer command tree into typed operation metadata and the browser deterministically maps selected controls to the fixed internal runner. No operating-system shell or browser-selected executable is introduced.

The backend path remains:

`Web controls -> fixed operation catalog -> Scope/Policy/Approval -> sric.web_console_runner -> product CLI implementation`

This preserves one implementation of product behavior while making the Web surface usable without memorizing commands.

### Security invariants

- `shell=False` remains mandatory.
- stdin remains disabled.
- user-supplied free-form argv is disabled in the primary Web UI.
- same-origin CSRF protection remains required for submission/cancellation.
- mutating operations remain approval-gated.
- destructive operations remain explicitly human-confirmed.
- secret redaction, output bounds, runtime bounds, cancellation, SSE activity, and fixed executable selection remain unchanged.
- external/imported content remains untrusted data.

### Verification added

Regression coverage now checks that every public CLI parameter has a structured Web control, choice metadata maps to selectors, the schema advertises `user_supplied_argv: false`, and the Workbench does not contain the former free-form argv controls.
