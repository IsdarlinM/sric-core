# SRIC Core 0.5.16 release candidate

SRIC Core 0.5.16 hardens the shared Sentinel Forge Security Workspace after a real FossilScope Windows run produced `TypeError: unsupported CLI parameter type in Web catalog: TyperArgument` and HTTP 500 from `/api/v1/workbench/catalog`.

The candidate requires executed evidence for:

```bash
python -m pytest -q tests/e2e/test_cli_all_commands_functional_v0514.py
python -m pytest -q tests/e2e/test_security_workspace_v0514.py tests/e2e/test_all_public_cli_web_surfaces_v058.py
python -m pytest -q tests/security/test_web_catalog_resilience_v0515.py tests/security/test_web_surface_guardrails_v0516.py tests/security/test_web_workbench_api_v056.py
python -m sric.standalone_gate --root .
python scripts/release-gate.py
```

Expected Web contract:

- real Typer arguments serialize without exception;
- every public parameter maps to a supported typed control;
- catalog/coverage/runtime faults are controlled and redacted;
- mutation classifications fail closed;
- recovery controls remain functional;
- fixed-runner, CSRF, approval and secret-redaction controls remain intact.

Merge status does not substitute for execution. Zero-step jobs are infrastructure evidence only.
